# Alaknanda Thakur - Personal Portfolio

Responsive personal portfolio web application for Full Stack Development Assignment-1.

## Run locally

Open `index.html` in a browser. The page uses Bootstrap 5 from its CDN and has no build step.

## Features

- Semantic HTML5 sections for profile, about, education, skills, projects and contact
- Responsive Bootstrap navigation, grid, cards, table and form components
- Dark/light theme switching
- Project category filtering
- Client-side contact-form validation with dynamic status messages
- Dynamic current year in the footer
